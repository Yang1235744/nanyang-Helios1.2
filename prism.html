架构总览

三件套协同工作：ByteTextEncoder 编码文本 → Self-DiT 在潜空间去噪 → SelfVAE 解码还原画面。

【Prompt】 ──> "雪地里的红狐"
│
▼
[ByteTextEncoder]   259 词表（字节级 UTF-8）· Transformer 4层 · [B, L, 512]
│
▼
[Self-DiT]   Spatial-Temporal Attention · AdaLN-Zero · SwiGLU MLP
    输入: latent [B,4,T,H,W] + timestep embedding
    条件: text_emb [B,L,512]
    位置编码: 三维分离 (T/H/W)，杜绝时序错位
    输出: velocity_pred v = ε - x₀
│
▼
[EDCISampler]   Rectified Flow · 增强 DPM-Solver++ · cfg_scale=3.5
    采样步数: 28步高质量；30秒视频通过 chunked sampling（每次64帧，分5次推理拼接）实现
    目标: x₀ = xt - t·v_pred
│
▼
[SelfVAE]   Encoder: AvgPool3d(1,2,2) 纯空间下采样
    Decoder: nn.Upsample(scale_factor=(1,2,2)) 精确恢复时序维度
    关键设计：kernel[0]=stride[0]=1，时间维度 T 全程不变
    下采样 8× 空间 · 4 通道潜空间 · temporal_reg 防花屏损失
│
▼
[Output]   图片 [3,1024,1024] 或 视频 [3,T,1024,1024] FPS×30s

能力规格

v2.0.2 正式版新增的两项核心能力。

Flux / SDXL 双通道优化

构图适配双通道：Flux 通道负责高保真细节与文字排版，SDXL 通道负责快速批量出图；配合批量推理加速，单卡可并发出图，吞吐显著提升。

口型同步 + 剧情对白自动生成

视频生成时自动对齐人物口型与对白音频，按剧情分段生成台词与画面，适合短剧、讲解、数字人播报等场景。

防花屏解决方案

旧版常见花屏问题及其成因对照：

症状旧版原因H2.0 解法
视频开头/结尾闪烁AnimateDiff 使用非因果 3D 卷积，未来帧信息泄露到当前帧encoder 使用 AvgPool3d(kernel=(1,2,2))，空间下采样不影响时序维度，帧间保持连续
画面随机出现噪点块VAE 解码器无时序约束，相邻帧之间不一致decoder 使用 nn.Upsample(scale_factor=(1,2,2)) 精确恢复 T 维度，配合同步训练 temporal_reg 损失
长视频（>10s）严重花屏逐段生成再拼接，边界处产生跳变单次端到端生成整个时间段，chunked sampling（每次64帧）全程自回归一致性
单张图片模糊或有伪影SDXL Turbo 步数太少（4步），细节丢失Self-DiT 用 EDCI Sampler 28 步高质量推理，NaN-safe clipping 防止初始化爆炸

训练流程

两阶段训练：先训 VAE 重建能力，再训 DiT 生成能力。全部基于本地训练数据。

Phase 1

VAE 重建训练（~5k steps）

冻结时间维度 KL，只做 L1 像素重建损失。
让编码器学会压缩，解码器学会还原。

python scripts/train_vae.py \
  --data-dir ./data \
  --epochs 10
Phase 2

VAE KL 正则化（~5k steps）

线性 warmup KL 权重：1e-6 → 1e-3。
让潜空间分布更紧凑，提升后续 DiT 稳定性。

python scripts/train_vae.py \
  --warmup-kl --epochs 10
Phase 3

Self-DiT 训练（~20k+ steps）

加载冻结的 VAE，训练 DiT 用 Rectified Flow 学习从噪声到数据的映射。
支持高分辨率（max 1024×1024）和任意时长视频。

python scripts/train_dit.py \
  --data-dir ./data \
  --vae-checkpoint path/to/vae_latest.pt \
  --epochs 30

快速开始

克隆仓库后，按以下三步即可训练属于自己的生成模型。

# Step 1：克隆源码
git clone https://github.com/Yang1235744/nanyang-Prism-Max-H2.0.git
cd nanyang-Prism-Max-H2.0
pip install -r requirements.txt

# Step 2：准备数据（图片目录 + 对应 .txt 描述文件）
mkdir -p data/images data/videos
#   把图片放入 data/images/，视频放入 data/videos/
#   每个图片/视频旁放同名 .txt 作为 caption，例如：
#     data/images/red_fox.png  →  data/images/red_fox.txt ("雪地里的红狐")

# Step 3：训练
python scripts/train_vae.py --data-dir ./data
python scripts/train_dit.py --data-dir ./data \
    --vae-checkpoint ~/.cache/nanyang-prism-h20/models/vae_latest.pt

# Step 4：生成
python scripts/generate.py --prompt "雪地里的红狐" --type image
python scripts/generate.py --prompt "海浪拍打礁石" --type video --duration 30

结果保存在 ~/.cache/nanyang-prism-h20/{images,videos}/
