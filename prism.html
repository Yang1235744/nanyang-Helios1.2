工作流：先收集数据，再本地训模

MiniMax H3 是训练阶段用的数据源；训好的模型会分发给用户离线运行，无需任何云端依赖。

Step 1 · 数据收集

从 MiniMax H3 拉样本

准备提示词列表，批量生成高质量图文/视频样本写入本地数据集：

git clone https://github.com/Yang1235744/nanyang-Prism-Max-H1.7.git
cd nanyang-Prism-Max-H1.7 && pip install -r requirements.txt
cp .env.example .env          # 填入训练密钥
python scripts/train_data.py --prompt-list prompts.txt --out-dir data/training

API 密钥仅用于训练数据采集，训完即可撤出内存

Step 2 · 本地训练

GPU 训出自己的模型

在本地 GPU 上对采集的数据集进行蒸馏 / 微调，产出可离线运行的权重：

python scripts/train_model.py \
  --data-dir data/training \
  --epochs 30 --out runs/prism_v1

训练完成后可将权重推送到 GitHub 或 NAS 分发

Step 3 · 离线使用

拉取训练成果，本地推理

训练好之后其他用户下载权重，本地 GPU 即可运行，无需连接任何外部服务：

git pull           # 或从 NAS 下载
python -m prism.infer --ckpt runs/prism_v1/best.pt --prompt "..." --t image
