引擎一览

三个引擎，统一 BaseAdapter 接口，按需切换。

引擎模态联网需求首次下载大小说明
SDXL Turbo图片❌ 纯本地~4 GB高清出图，4 步推理，速度极快
AnimateDiff视频❌ 纯本地~8 GB15 秒带音频真视频，无端点限制
MiniMax H3图 + 视频✅ 需 API Key—可选备用通道，需要时配置密钥

快速开始

装完依赖，第一次会自动从 HuggingFace 下载权重（只下一次），之后完全离线运行。

# Step 1：克隆并安装
git clone https://github.com/Yang1235744/nanyang-Prism-Max-H1.7.git
cd nanyang-Prism-Max-H1.7 && pip install -r requirements.txt

# Step 2：初始化本地引擎权重（只需一次）
python scripts/download_weights.py --engine sdxl
python scripts/download_weights.py --engine animatediff

# Step 3：出图 / 出视频
python scripts/generate.py --engine sdxl \
    --prompt "雪地里的红狐 高清摄影"
python scripts/generate.py --engine animatediff \
    --prompt "海浪拍打礁石 慢镜头" --t video --duration 15

生成结果保存在 ~/.cache/nanyang-prism/{sdxl-cache,animatediff-cache}/

MiniMax H3 备用通道（可选）

如果你持有 MiniMax API Key，可额外启用这条通道作为备用：

# 设置环境变量
export MINIMAX_API_KEY="sk-api-xxx"
export MINIMAX_API_BASE="https://minimax.api.easyframe.cn/api/v3"

# 或写入 .env 文件（不提交到 git）
cp .env.example .env
vim .env          # 填入真实密钥后保存

# 使用 mini-max 引擎
python scripts/generate.py --engine minimax-h3 \
    --prompt "赛博朋克城市夜景" --t image
