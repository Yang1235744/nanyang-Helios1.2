引擎一览

两个引擎，统一 BaseAdapter 接口，由 GPT 按需切换调用。

引擎模态联网需求首次下载大小说明
SDXL Turbo图片❌ 纯本地~4 GB高清出图，4 步推理，速度极快
AnimateDiff视频❌ 纯本地~8 GB最高 30 秒带音频真视频，无端点限制

与 nanyang-GPT 联动

GPT 是大脑，Prism 是专干活的小弟。GPT 输出标记 → 自动触发生成 → 结果带回聊天。

Step 1

GPT 识别意图

用户说"帮我画一只红狐"，GPT 在回复中加入生成标记：

<|gen_image|>
雪地里的红狐，高清摄影，自然光
<|/gen_image|>
Step 2

解析并调用引擎

GPTChatAdapter 自动识别标记，交给对应引擎执行：

from prism import GPTChatAdapter
adapter = GPTChatAdapter()
results, reply = adapter.handle_gpt_output(gpt_reply)
Step 3

结果带回用户

图片和视频保存在本地缓存目录，用户在聊天中直接看到生成的预览和路径。全程无需跳转任何界面。

独立使用

不依赖 GPT，也可以直接用命令行生图生视频。

# Step 1：克隆并安装
git clone https://github.com/Yang1235744/nanyang-Prism-Max-H1.7.git
cd nanyang-Prism-Max-H1.7 && pip install -r requirements.txt

# Step 2：初始化本地引擎权重（只需一次）
python scripts/download_weights.py --engine sdxl
python scripts/download_weights.py --engine animatediff

# Step 3：出图 / 出 30 秒真视频
python scripts/generate.py --engine sdxl \
    --prompt "雪地里的红狐 高清摄影"
python scripts/generate.py --engine animatediff \
    --prompt "海浪拍打礁石 慢镜头" --t video --duration 30

生成结果保存在 ~/.cache/nanyang-prism/{sdxl-cache,animatediff-cache}/

Python API

直接在你的项目里调用，完全可控。

from prism import get_engine, GPTChatAdapter

# —— 方式一：直接调引擎 ——
img_client = get_engine('sdxl')
path = img_client.generate_image("一只在雪地里奔跑的红狐")

vid_client = get_engine('animatediff')
path = vid_client.generate_video("海浪拍打礁石", duration=30)

# —— 方式二：让 GPT 自动调度 ——
adapter = GPTChatAdapter()
results, user_text = adapter.handle_gpt_output(gpt_reply)
