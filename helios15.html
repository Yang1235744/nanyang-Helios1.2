特性

在 1.2 早期版基础上补齐的关键能力。

NEW

15 秒长视频

时空解耦注意力：空间注意力逐帧、时间注意力跨帧，避免 180 帧全注意力的二次方开销，让 15 秒视频可在单卡上训练与生成。

NEW

同步音频生成

AudioVAE 把 mel 谱压缩到 latent，AudioDiT 以文本+视频为条件做 1D 流动匹配，生成与画面同步的 15 秒音轨（24kHz）。

UPGRADE

高清图片

VAE 升级到 base 128、16 通道 latent，承载 1024px 细节；训练分辨率与 latent 空间同步扩展。

NEW

捆绑南阳 GPT

中等对话大模型，通过工具调用标记 <|gen_image|> / <|gen_video|> 触发 Helios 生成 —— 聊天与生成在同一个模型里完成。

字节级文本编码器

自研 UTF-8 字节级 tokenizer（词表 259），中英文 prompt 原生支持，不依赖任何预训练。

Rectified Flow

直线流匹配 + Euler 采样 + CFG，统一驱动视频/图片/音频三种生成任务，实现简洁稳定。

架构

南阳 GPT 调度 + 视频/图片 DiT + 音频 DiT，三股生成能力合为一个中等模型。

快速开始

四阶段训练：VAE → DiT → 音频 → 南阳 GPT。

git clone https://github.com/Yang1235744/nanyang-Helios1.5.git
cd nanyang-Helios1.5 && pip install -r requirements.txt

# 四阶段训练
python -m helios.train --config configs/helios_medium.yaml --stage vae      # VAE
python -m helios.train --config configs/helios_medium.yaml --stage dit      # 视频/图片 DiT
python -m helios.train --config configs/helios_medium.yaml --stage audio    # 音频 VAE + AudioDiT
python -m helios.train --config configs/helios_medium.yaml --stage gpt      # 南阳 GPT

# 生成图片
python -m helios.sample --ckpt runs/helios15_medium/latest_dit.pt --prompt "雪地里的红狐" --type image

# 生成 15 秒视频 + 音轨
python -m helios.sample --ckpt runs/helios15_medium/latest_dit.pt \
  --audio-vae runs/helios15_medium/audio_vae.pt --audio-ckpt runs/helios15_medium/audio_dit.pt \
  --prompt "海浪拍打沙滩" --type video --out waves

路线图

从零起步，逐版本累积。

  1. Helios1.2 早期版 —— 统一图文/视频 DiT + 字节级文本编码器 + Rectified Flow。
  2. Helios1.5 中等版 —— 15 秒视频 + 音频 + 高清图片 + 南阳 GPT 捆绑，1.38B 参数。
  3. 因果 3D VAE —— 时间维压缩，更平滑的视频 latent，降低长视频显存。
  4. 规模扩展 —— 更大分辨率与帧数、EMA、logit-normal 时间步、分布式训练。
  5. 生态与分发 —— 模型仓库托管预训练权重、一行命令拉取即用 CLI、社区 fine-tune。
