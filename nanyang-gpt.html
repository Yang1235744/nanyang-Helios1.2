获取模型 —— 两种格式，两个通道

同一个模型，按你的运行时选通道。

通道一 · Ollama

GGUF 格式

转成 GGUF（gpt2 架构家族）后即可被 Ollama、llama.cpp 等本地运行时拉取使用：

pip install gguf
python -m nanyang_gpt.convert_gguf \
  --ckpt runs/nanyang_gpt/latest_gpt.pt \
  --out nanyang-gpt-f16.gguf --ftype f16

ollama create nanyang-gpt -f Modelfile
ollama run nanyang-gpt

拓扑与 GPT-2 一致（可学习位置嵌入、pre-norm、qkv 合一、GELU MLP、嵌入共享），转换器一行命令完成。

通道二 · 通用

PyTorch 格式

标准 .pt checkpoint，任何 PyTorch 项目 torch.load 即用；与 Helios1.5 内置对话模型同架构同配置，权重直接互换：

git clone https://github.com/Yang1235744/nanyang-GPT.git
cd nanyang-GPT && pip install -r requirements.txt

# 预训练权重见 Releases
python -m nanyang_gpt.chat \
  --ckpt runs/nanyang_gpt/latest_gpt.pt

快速开始

从零训练你自己的对话模型，语料即放即训。

# 语料：对话文本放进 data/corpus/*.txt
# 格式：用户：... 助手：...（需要生成时带上 <|gen_image|> / <|gen_video|> 标记）
python -m nanyang_gpt.train --config configs/nanyang_gpt_medium.yaml

# 聊天
python -m nanyang_gpt.chat --ckpt runs/nanyang_gpt/latest_gpt.pt

工具调用

聊天中发现生成意图，自动输出标记，交给 Helios1.5 执行。

模型输出标记

语料教会模型在该生成时输出 <|gen_image|>描述 或 <|gen_video|>描述。

运行时解析

parse_tool() 把回复拆成（文本, 工具类型, 生成提示词），Helios1.5 接管出图 / 出视频。
