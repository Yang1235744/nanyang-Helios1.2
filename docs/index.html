nanyang-Helios1.2

从零搭建的统一图片 / 视频生成模型。不依赖任何预训练权重 —— 文本编码器、VAE、Diffusion Transformer 全部自研自训，每一行都可以读、可以改、可以从头复现。

在 GitHub 上查看 快速开始

特性

早期版本坚持一件事：小、完整、可训练。

统一图文/视频 DiT

图片视为单帧视频（T=1），同一个 Diffusion Transformer 处理两种模态：时空自注意力 + 文本交叉注意力 + adaLN-Zero 调制。

字节级文本编码器

自研 UTF-8 字节级 tokenizer（词表 259），无需 sentencepiece / 预训练 embedding，中英文 prompt 原生通吃。

Rectified Flow

直线流匹配目标 v = ε − x₀，Euler 采样 + Classifier-Free Guidance，训练稳定、实现不足 50 行。

从零可训

两阶段训练：先训 TinyVAE 重建，再冻结 VAE 联合训练 DiT + 文本编码器。CPU 即可跑通全流程，GPU 开箱即用。

架构

latent 空间中的条件流匹配：prompt 与噪声进，像素出。

快速开始

Python 3.10+，装完依赖即可从零训练你自己的第一个 checkpoint。

git clone https://github.com/Yang1235744/nanyang-Helios1.2.git
cd nanyang-Helios1.2 && pip install -r requirements.txt

# 数据：图片放 data/images，视频放 data/videos（同名 .txt 为 caption，可选）
python -m helios.train --config configs/helios_tiny.yaml --stage vae   # 阶段一：VAE 重建
python -m helios.train --config configs/helios_tiny.yaml --stage dit   # 阶段二：扩散训练

# 生成
python -m helios.sample --ckpt runs/helios_tiny/latest_dit.pt --prompt "一只雪地里的红狐"
python -m helios.sample --ckpt runs/helios_tiny/latest_dit.pt --prompt "海浪拍打礁石" --type video --out out.gif

路线图

从零起步，逐版本累积。

  1. Helios1.2 早期版 —— 统一图文/视频 DiT + 字节级文本编码器 + Rectified Flow，CPU 可复现全流程。
  2. 因果 3D VAE —— 时间维压缩，更平滑的视频 latent；时空分解注意力降低长序列开销。
  3. 规模扩展 —— 更大分辨率与帧数、EMA、logit-normal 时间步采样、分布式训练。
  4. 生态与分发 —— 模型仓库托管预训练权重、一行命令拉取即用的 CLI、社区 fine-tune 生态。
