为什么本地

三模一体

聊天 LLM、Helios 图片生成、Helios 视频生成，全部打包进同一个软件，一个窗口全搞定。

本地算力

推理全在你自己机器上跑：有 NVIDIA GPU 自动加速，纯 CPU 也能跑。

无需登录

云端账户体系还没开放，当前版本零账户、零联网验证，打开就用。

数据不出机

会话记录与生成结果只存在你自己的 %APPDATA% 里，隐私天然有保障。

上手

01

下载并解压 nanyang-Chat-windows-x64.zip，双击 nanyang-Chat.exe。

02

（可选）放入模型权重：聊天 chat_latest.pt、生成 helios_latest_dit.pt，放到 %APPDATA%\nanyang-Chat\models\，重启软件。未放权重时对应功能会明确提示"未训练"。

03

底部切换 聊天 / 生成图片 / 生成视频 三种模式，Enter 发送。

系统要求

  • Windows 10 / 11（64 位）
  • 内存 ≥ 8 GB（建议 16 GB）
  • NVIDIA GPU 可选（自动启用 CUDA 加速）
  • 从零自研模型持续迭代中，权重与软件版本会一起在 Releases 更新
